# ai-bot-platform
ai-bot-platform — отдельный backend-сервис для AI-бота салона/платформы.

Сервис отвечает за:
- AI-консультации;
- маршрутизацию намерений пользователя;
- RAG по базе знаний;
- интеграции с MAX, сайтом, YClients и будущим мобильным приложением;
- хранение диалогового состояния;
- аналитику сценариев.
