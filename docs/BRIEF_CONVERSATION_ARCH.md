**Ветка от `origin/dev`, PR против `dev`, не против `main`.**

**Коммить и пушить промежуточное.** За неделю работа терялась на обрыве среды пять раз.

**PR открываешь сам, merge делает главное окно** после собственной проверки — не по твоему отчёту. Для бота — по зелёному CI. Для `beautygo_backend` — только с разрешения владельца: **merge в его `dev` есть немедленная боевая выкладка**.

## §6. Ловушки, выученные дорого. Читать перед первым замером

**Правильный код может быть не на том пути, которым идёт трафик.** За сутки поймано трижды: оркестратор без единого вызова, тенантное приветствие с нулём разговоров, весь реестр навыков мимо глобального пути. **Тесты этого не ловят — они проверяют код, а не маршрут.**

Любая задача «починить X» начинается с вопроса: **кто доходит до X на пилоте**.

**Докстринги о чужих системах врут чаще всех.** За сутки найдено десять ложных: `pipeline.py` про вызов из ingress; `ingress/views.py:13` про одно-значный гейт, снятый 15.08; сериализатор Ayla, уверявший, что салонная консоль читает версию брони, которой в её выдаче нет. Их не перечитывают, когда правят описываемое.

**Отрицательный результат от сломанного инструмента неотличим от настоящего.** За сутки: `sudo grep` без прав дал «ноль обращений»; `cat` на `.gz` прочитал 2 файла из 16; `head -16` показал 8 маршрутов из 14; запрос подписок MAX устаревшим способом дал «0 подписок у обоих ботов». **Проверять инструмент обязательно тогда, когда он показывает ноль.**

**Счёт и показ — разные операции.** Сначала `grep -c` или `wc -l` **без обрезки**, потом отдельной командой образец. Если в выводе есть `head` — число оттуда брать нельзя.

**Git Bash на Windows** искажает `origin/dev:.файл` в `origin\dev;.файл`, если имя после двоеточия начинается с точки. Ставь `export MSYS_NO_PATHCONV=1`.

**В свежем worktree** может не быть dev-зависимостей, и `uv run pytest` тогда **молча падает в глобальный Python**. Проверь, что pytest из `.venv`; при необходимости `uv sync --extra dev --extra ai-core --frozen`.

**Двойной `-q`** в pytest съедает итоговую строку `N passed` — провал выглядит как успех. Гоняй через `-o addopts=...`, чтобы видеть счёт.
