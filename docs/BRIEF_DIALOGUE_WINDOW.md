## 3. Где на пилоте живёт разговор — читать до открытия кода

Клиентский бот идёт **глобальной тропой** `ingress:max_global`, бестенантной. **Реестр навыков там не диспетчеризуется вовсе.**

```
-> apps/orchestrator/concierge.py :: generate_concierge_reply

```

**`apps/orchestrator/pipeline.py`** — 19 шагов, 92 зелёных теста — **на живом пути не вызывается ни разу**. `intent_router.classify_intent` — тоже. Правка в них будет корректной и мёртвой.

Это уже происходило: 21.08 пять исправлений канона выложены в тенантную тропу и не исполняются ни одним разговором.

**Правило: для каждого изменения отвечай отдельной строкой, какой тропой оно исполняется на пилоте сегодня.** Ответ «тенантной» означает «не исполняется».
