## 1. Рантайм ушёл вперёд триажа

Триаж 31.08 дал **3 SP** с формулировкой «механизмы существуют, UX
поверх них — нет» (`docs/BACKLOG_TRIAGE_2026-08-31.md:330`).

Delta-check на сегодняшней базе (§115) показывает, что **UX построен**:

| действие | состояние | доказательство |
|---|---|---|
| список записей | есть, реальные данные | `CustomerRecordsScreen.tsx` ← `GET /bookings/list` |
| карточка записи | есть, «THE main screen» из спеки | `CustomerBookingDetailScreen.tsx` |
| отмена | **двухшаговая, с окном отмены отмены** | там же: `cancelBookingRequest` → снекбар → `cancelBookingConfirm` / `cancelBookingUndo` |
| перенос | есть, канонический адрес (DRF-1481) | `RescheduleScreen.tsx` |
| оценка визита | есть | `FeedbackScreen.tsx`, вход из карточки и из списка |
| честный 404 | есть | «Этой записи больше нет» вместо пустого экрана |

Причём **права на действия приходят с сервера**, а не вычисляются
экраном: `cancellable`, `reschedulable`, `can_rate` (past + confirmed +
unrated). То есть поверхность не решает за домен, можно ли отменить, —
она показывает то, что домен разрешил.

**Оценивать этот кусок как ненаписанный было бы ошибкой на весь трек.**

## 3. Ноль по имени, который НЕ дефект

Маршруты `/my-visits`, `/my-visits/:id`, `/my-visits/:id/reschedule`
смонтированы, а ссылок на них в продуктовом коде **ноль**: все шесть
переходов ведут на `/customer/records`.

Похоже на дубль поверхности. **Не дубль.** Рядом лежит тест, который
называет причину:

> «The legacy `/my-visits/:bookingId` route stays mounted **on purpose**
> … (external deep links)»
> `App.customerRecordRoute.test.tsx:13,96`

Это §116 в чистом виде: ноль по имени совместим с «не подумали» и с
«подумали и оставили намеренно», и различает их только поиск
защищаемого действия. Здесь действие — переход по старой ссылке из
ранее отправленного сообщения бота.

Положительный контроль поиска поставлен: тем же способом
`customer/records` находится в трёх `.py`/`.md` — значит ноль настоящий,
а не следствие кривого запроса.

**Открытый вопрос, а не работа:** живут ли такие ссылки ещё. Это
измеряется по отправленным сообщениям бота, и до замера снимать алиас
нельзя.
