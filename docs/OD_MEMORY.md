## Развёрнутая формулировка владельца

> `UserPersonalContext` — source of truth; текущий consent-path временно разрешаем как **явно зарегистрированное исключение** с Privacy/Legal review; между тенантами переносятся **только факты, которые пользователь сообщил о себе сам**; «удалить всё» = удалить память/профиль и **обезличить переписку с гарантией недоступности для prompt pipeline**; постоянная память **не используется как основание WHY**, только для связности и чтобы не переспрашивать.

## 1. Источник истины — бэкенд

**`users.UserPersonalContext` в бэкенде владеет объявленными предпочтениями.**

Память бота — слой **захвата и приватности**: зоны чувствительности, надгробия, шифрование, происхождение факта. **Не власть.**

Следствие: мост становится односторонним для объявленных полей. Бот извлекает и предлагает, бэкенд владеет. `MemoryEntry` держит то, под что у бэкенда нет поля, плюс приватную машинерию.

## 2. Согласие — зарегистрированное исключение, не новый поток

**Нынешний широкий путь разрешён временно, как явно зарегистрированное исключение.**

**Обязательно:** запись в Consent Scope Registry с причиной и сроком + **Privacy/Legal review**. Незаявленное отклонение — и есть настоящая экспозиция.

**Поток предложения факта не строим.** Он противоречит решению 09.07 «пилот не задаёт вопросов о памяти активно».

## 3. Переход между салонами — только самосообщённое

```
переходит       то, что человек сказал о себе сам
                диета, удобное время, район, ценовой диапазон

НЕ переходит    любимые мастера            отношение с конкретным салоном
                сигналы из истории записей  наблюдение салона
                чувствительность кожи       наблюдаемо салоном, близко к здоровью
```

**Правило, применимое к любому будущему полю: сказал сам — переходит; узнали о нём — нет.**

Следствие: `MemoryEntry.source_tenant_id` перестаёт быть «информационным» и становится проверяемым при чтении.

## 4. «Удалить всё» — память удалить, переписку обезличить

**Память и профиль удаляются.**

**Переписка обезличивается**, а не удаляется — это единственная запись того, что бот на самом деле сказал человеку, и она нужна при разборе инцидента и спора о брони.

**Обязательное условие, без которого решение не исполнено:** обезличенная переписка **не должна быть достижима ни из одного пути, ведущего в промпт**. Гарантия, а не намерение — доказывается прогоном.

**Срок хранения обезличенного назвать явно.** «Бессрочно» — отсутствие решения.

## 5. Память и WHY — только связность

**Постоянная память не является основанием рекомендации.**

```
можно     бот помнит сказанное и не переспрашивает
нельзя    «тебе это подходит, потому что ты предпочитаешь…»
```

Подтверждает и уточняет решение по C04 (`OD_C04_GROUNDED_WHY.md`): WHY — пересказ текущего разговора.

**Следствие для стоимости:** памяти не нужны ни доказательная привязка, ни ранжирование, ни объект свидетельства. Ей достаточно быть **верной и видимой**.
