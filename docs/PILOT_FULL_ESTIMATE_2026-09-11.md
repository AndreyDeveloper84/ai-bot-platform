## 1. Что такое пилот — одной строкой

**Controlled Pilot = 3–5 реальных человек в реальном MAX, один настоящий салон
(`formula-tela`, «Формула тела», г. Пенза, ул. Пушкина, д. 45 — §10) плюс соло-мастера,
реальные расписание и бронь, ограниченный Product Brain; не demo.**

«Работает» означает, что **сквозной путь проходит без молчаливой лжи**: человек входит → видит
каталог/подбор → задаёт цель → получает рекомендацию только из `VERIFIED` (или честный
`NO_VERIFIED_CANDIDATES`) → бронирует с гейтом здоровья → видит адрес и дату → может отменить,
перенести, удалить аккаунт; каждый шаг оставляет событие, по которому инцидент расследуем; выкладку
можно откатить. Определение из матрицы §2, критерии — §133 (не урезаем основную продуктовую
ценность) и §138 (ИСПОЛНЕНО = построено, включено **и доступно человеку**).

Что пилот **не** обязан: весь BeautyGO, Plan Engine, множественные цели, аналитическая шина,
аватар (матрица §8, свод §15).

## 6. Пределы этой оценки — чего не оценили и почему

1. **61 лист ПОДЛЕЖИТ без SP** в 18 направлениях — не оценивались здесь поштучно: у каждого
   нужен замер по коду (как в `PILOT_BLOCKERS_COST.md`), иначе число — впечатление. В таблицах
   выше они присутствуют только там, где направление само назвало число (DRF-1319, 1330, 1329,
   1687, 1699, 1622, 1623, 1612).

   «≈ 20» получен по доле слитых PR, а не по SP срезов — это грубее любой другой строки.
3. **B-3 не оценён** — по той же причине, что 09.09: контракт производителя не назван (DRF-1620).
   Сегодняшние #1559/#1600 — половина; сколько во второй, скажет DRE-окно.
4. **Состояние «слито / в очереди» прочитано по заголовкам PR** через `gh pr list`, а не по
   содержимому диффов. Заголовок вида «половина производителя» принят на веру. Строки «не начато»
   по B-5.2, B-7.1, B-7.2, §7, §12, DRF-1627 сверены содержимым `origin/dev` (grep 11.09 ~14:30 UTC).
5. **Состояние направлений в Linear снято утром 11.09** (dev@febdf9c0); часть строк «не
   начато» могла закрыться слияниями после — таблицы сверялись со списком слитых PR на 14:10 UTC,
   но не с содержимым `dev`.
6. **Числа поверхности** (сколько `verified`, координат, мастеров с расписанием) в черновике не
   приведены — см. шапку; вписать из `SURFACE_STATE.md`.
7. **Не входит ни в одну сумму:** время на согласование между окнами; простой очереди слияний
   на защищённом `dev`; перевыкладки обеих сторон при смене токенов; решения владельца как
   длительность (они блокируют вход, а не работу).
8. **Столбец «кто»** заполнен там, где окно назвало себя в PR или в направлении. Сегодняшняя
   перезагрузка окон (все имена сменились) делает столбец ненадёжным на завтра.
9. **Оценка не прогонялась**: ни один срез не прототипировался; все числа — чтение кода и
   документов.
10. Разделение «обязательно / может подождать» — **мнение исполнителя**, кроме строк, где
    источник — прямое слово владельца (§138 фотосканер, §133 «не урезаем», P0 DRF-1627).
    Владелец вправе переставить любую строку; тогда меняется §5.
