## Риск 2 подтверждаю — и он глубже, чем ты предположил

Проверил `users/models.py` на `origin/dev` бэкенда:

```python
diet_type = models.CharField(max_length=20, choices=DietType.choices, blank=True, default="")

class DietType(models.TextChoices):
    OMNIVORE, VEGETARIAN, VEGAN, KETO, HALAL, KOSHER, OTHER
```

**Полей `excluded_foods` и `user_note` нет вовсе.** Целевая форма из решения в приёмник не ложится — ты прав.

**Но есть вторая часть, которую ты не мог увидеть, не открыв перечень.** В нём `halal` и `kosher`.

Решение владельца говорит: **«Не ем свинину» -> явное пищевое ограничение, но нельзя выводить религию.**

А перечень предлагает ровно этот вывод как готовое значение. То есть **схема приёмника подталкивает к тому, что решение запрещает**.

Это не мелочь формы. Присвоить человеку `halal` по фразе «не ем свинину» — сделать вывод о вероисповедании из пищевой привычки. Такой вывод и есть фабрикация факта, только с более высокой ценой ошибки.

**Что с этим делать — не решай сам.** Расширение приёмника это PR в `dev` Ayla, то есть **боевая выкладка**, и трогать перечень значений — отдельное решение. Опиши в отчёте, как надо, и остановись на границе.

**Пока приёмник не расширен:** сохраняй то, что человек сказал, в том виде, который приёмник принимает без искажения. Если сказанное не ложится — **лучше не сохранить, чем сохранить неверно.** Это прямо следует из запрета на фабрикацию.

## Ответ 2 — 2026-08-23. PR #1230 упал одной строкой

Настоящий прогон CI красный. Причина одна:

```

```

`mypy` в этом репозитории проверяет `apps config tests` — то есть и приёмочные тоже. Файл импортирует `requests`, а типов для него в окружении нет.

**Я бы не исключал каталог целиком** — это снимет проверку и с будущих файлов там. Первое честнее.

### Не пугайся трёх «fail» в `gh pr checks`

Их три, и ни один не настоящий. Это **самоотмена docs-skip**: твой PR смешанный — трогает и `docs/**`, и `tests/acceptance/*.py`. Парная работа обнаружила код и сняла себя, чтобы не выдать ложный успех вместо вердикта настоящего `ci.yml`.

В логе прямо: «Mixed PR — non-docs files detected. Real ci.yml will run; cancelling this docs-skip run».

`gh pr checks` не различает отменённое и упавшее. Смотри `gh run view <id> --json conclusion`: `cancelled` — не `failure`.

Три файла уезжают в git и **не будут гоняться никогда**: имена не подходят под `test_*.py`.

Твоё объяснение верное — это harness'ы, им нужна живая инфраструктура. Но мы третий день ловим один класс: код есть, выглядит защитой, защитой не является. 259 фронтовых тестов не гонялись, 440 в `tests/` не гонялись, гейт `replay` зеленел вхолостую.
