## Решения владельца

### OD-CAT-1 (23.08) — «бёдра» это не дубль, а два уровня зоны

> «бедра полностью значит все зоны, а поверхность передняя/задняя/боковая часть — это одна зона»

- `Бёдра полностью` — 1700 ₽ — **вся зона**, три поверхности
- `Лазерная эпиляция бёдер (передняя/задняя/боковая часть)` — 850 ₽ — **одна поверхность на выбор**

Поштучно три вышли бы 2550 ₽ — «полностью» продаётся со скидкой. Обе строки верны, обе остаются.

**Следствие:** узор «часть → целое» повторяется в лазерной эпиляции трижды:

| Часть | Цена | Целое | Цена |
|---|---|---|---|
| Бёдра, одна поверхность | 850 | Бёдра полностью | 1700 |
| Руки до локтя | 1100 | Руки полностью | 1600 |
| Голени с коленями | 1700 | Ноги полностью | 2800 |

Канон это уже умеет: «рук до локтя» и «рук полностью» — отдельные шаблоны, «голеней» и «ног полностью» тоже. **Не хватает только разбивки бёдер по поверхностям.**

Бикини — **другая ось**: по линии белья 600 → глубокое 1400 → тотальное 1600 это глубина захвата, а не части одной зоны.

## Открытые вопросы владельцу

### В-1. Слэш означает противоположное в разных строках

| Строка | Цена | Смысл слэша |
|---|---|---|
| RF-лифтинг — Лицо/шея | 1300 | **И** — добавили декольте, стало 1700 |
| RF-лифтинг — Лицо/шея/декольте | 1700 | **И** |
| Лазерная эпиляция бёдер (передняя/задняя/боковая) | 850 | **ИЛИ** — решено OD-CAT-1 |
| Вибромассаж — Бёдра/ягодицы | 1200 | **?** |
| Вибромассаж — Спина/руки | 1200 | **?** |
| Массаж лица пластический / скульптурный | 1500 | **?** — похоже на синонимы одной услуги |

Одинаковая цена у обеих пар вибромассажа наводит на «процедура по области», то есть **И**. Требует подтверждения.

### В-2. Как записать выбранную поверхность бедра

Клиент выбирает одну из трёх — а бронь несёт только `service_id`. **Мастеру негде узнать, какую.**

Предложение: три отдельных шаблона канона (передняя / задняя / боковая) вместо одного с примечанием. Канон уже так устроен — зоны это отдельные шаблоны, поля-модификатора в нём нет вовсе.

### В-3. Час на верхнюю губу

У всех лазерных зон стоит `duration_min = 60`, включая верхнюю губу за 500 ₽. Слот блокируется на час. Ломает запись сильнее кривых имён.

### В-4. Нулевая цена

`Карбокситерапия+пилинг` и `Массаж шейно-воротниковой зоны` — `price_from = 0.00`, клиенту покажется бесплатным.

## Гигиена имён салона (58 строк)

| Дефект | Строк | Пример |
|---|---|---|
| Длительность внутри имени | 11 | `Массаж спины — глубокая проработка (45 минут)` |
| Голая зона без модальности | ~10 | `Подмышки`, `Ягодицы`, `Верхняя губа` |
| Маркетинговое имя | 4 | `Must Have`, `Классика`, `Super` |
| Двойной пробел | 2 | `Бёдра  полностью`, `Бикини  по линии белья` |
| Обрезано на полуслове | 1 | `Всё тело (руки полностью,ноги полностью,тотальное бикини,подмышки.` |

Обрезанное пришло таким **из YClients** — поле в базе `varchar(200)`, длина строки 65, импорт ни при чём.

**Сличать по именам напрямую нельзя:** канон пишет «бедер», «щек» — салон «Бёдра». Ё и е разойдутся, нужна нормализация при сопоставлении.

## Разрывы канона, найденные при первом сличении

- **`Бикини тотальное`** — в каноне есть классическое, глубокое и межъягодичная зона, тотального нет
- **Комплекс `Super`** (ноги полностью + глубокое бикини + подмышки) — в каноне три комплекса, этого среди них нет
- **Бёдра по поверхностям** — см. В-2
