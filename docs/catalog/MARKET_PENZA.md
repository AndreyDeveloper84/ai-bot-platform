## Что этот срез говорит про канон

**Курс, а не процедура.** Лазерная эпиляция на рынке продаётся пакетами по 6–8 сеансов. В каноне понятия курса нет вовсе — только разовые шаблоны. Наш пилот тоже продаёт разово.

**Пол — ценовая ось, а не отдельная услуга.** У Медиклиника пол меняет цену на десяти зонах. В каноне мужские варианты сделаны отдельными шаблонами и только для пяти зон (грудь, спина, борода/шея, подмышки, интимные). Для «бедро ж 5 500 / бедро м 6 500» такой формы не хватает.

**Длительность — тоже ценовая ось.** УЗ-чистка 30 мин 1 700 против 50 мин 2 500 у одного салона. RF-лифтинг 30/50 так же.

**Зоны, которых в каноне нет:** бакенбарды · периареолярная зона · стопы · плечи. Плюс «предплечье» — это наше «руки до локтя» под другим именем, синоним нужен для поиска.

**Длительности рынка против наших.** У нас у всех лазерных зон стоит 60 минут. Рынок: подмышки 15, лицо 15–20, глубокое бикини 20–30, ноги полностью 45. **Наша верхняя губа за 500 ₽ держит часовой слот вместо десяти минут.**

### Проверено живым вызовом

```
город=Пенза            -> 9 мастеров из пяти салонов
город=Москва           -> 0
```

Фильтр по городу отрабатывает. Город хранится на арендаторе **в боте** (`tenancy_tenant.city`), не на мастере — у мастеров поле адреса пустое даже у пилотного салона.

### Как снести одной командой

Все услуги помечены `source='seed'`, все арендаторы имеют slug с префиксом `mkt-`.

```python
# Ayla:  docker exec -i dev-web-1 python manage.py shell
from django.apps import apps as A
from django.db import transaction
T = A.get_model("tenants", "Tenant"); U = A.get_model("users", "User")
with transaction.atomic():
    ids = list(T.objects.filter(slug__startswith="mkt-").values_list("id", flat=True))
    A.get_model("services","SpecialistService").objects.filter(tenant_id__in=ids).delete()
    A.get_model("services","SalonService").objects.filter(tenant_id__in=ids).delete()
    A.get_model("users","SpecialistProfile").objects.filter(tenant_id__in=ids).delete()
    U.objects.filter(username__startswith="mkt-").delete()
    T.objects.filter(id__in=ids).delete()

# бот:  docker exec -i ayla-bot-staging-web-1 python manage.py shell
from django.apps import apps as A
A.get_model("tenancy","Tenant").objects.filter(slug__startswith="mkt-").delete()
```

Графики уйдут каскадом за мастерами. После сноса — прогнать синхронизацию каталога.
