Verdict checklist · Manrope

  • Кириллица: «й» / «ё» / hooks читаются на 13–15dp без артефактов
  • «щ» / «ц» / «ъ» / «ь» — equal proportions, не сжаты
  • Wide cyrillic не разрывает строки в кнопках 44dp
  • Weight contrast 400 ↔ 600 различимо на body 15px
  • Tabular numerals (tnum) активируются для «1 800 ₽» / «16:00» / «1 240 / 2 100»
  • Currency «₽» правильной высоты + расстояние до числа
  • «ёлочки» — углы, не подменены на " "
  • Em dash — длина и kerning соответствует европейской типографике
  • Italic / oblique (если есть) — не ломает русские глифы
  • Display 32–48px — letterspacing −2.5%/−3.5% не схлопывает соседние буквы
Если ≥2 пункта fail — switch --ff-display и --ff-body на 'Onest', заново render. Финальный verdict + screenshot фиксируется в docs/design/assets/AYLA/EXPERIMENTS/README.md.
