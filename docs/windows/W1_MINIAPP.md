# Окно W1 — Mini App не доезжает до людей

Ты главное окно этого потока. Работай своими сабагентами, если задача крупнее одного захода.

## Зачем поток

Mini App написан — 55 экранов — и **почти никем не используется**. Салонный и мастерский боты его открывают, клиентский нет. А собранный фронт устаревает, потому что его никто не собирает конвейером.

## Задачи

```
DRF-1257  фронт Mini App не собирается ни одним конвейером   3 SP
DRF-1326  маршруты строятся в двух формах, одна в никуда     3 SP
DRF-1323  из бота нет ни одной кнопки в Mini App             3 SP
DRF-1066  нет экрана успеха — человек создал ДВЕ брони       — SP
DRF-1226  /api/v1/me отдаёт 400 в 8 обращениях из 9          2 SP  ← БЛОКЕР
```

**Порядок обязателен.** DRF-1326 **раньше** DRF-1323: если сначала заполнить настройку, мёртвые кнопки появятся из ничего. Фикс 1326 уже написан — ветка `fix/drf1326-miniapp-routes`, коммит `503bdcb`, 484 строки, с тестом, читающим маршруты из `App.tsx`. **Не влит, и Linear об этом не знает.** Начни с проверки, жив ли он после свежего `dev`.

**DRF-1066 самый дорогой по последствиям:** живой человек 14.08 нажал дважды и создал две подтверждённые брони к разным мастерам. Это не UX, это данные.

**DRF-1226 — блокер по решению владельца 24.08.** Причина 400 не установлена. **Первый шаг — замер и имя вызывающего**, а не правка. Если 400 ловит Mini App — это подтверждает решение; если нет, скажи прямо.

## Территория

Твоя: `apps/miniapp/**`, `apps/skills/welcome/skill.py` **в части построения ссылок Mini App**, конвейеры сборки, `apps/channels/max/staff_menu.py`.

**Занято другими окнами прямо сейчас — не входить:**

```

apps/skills/welcome/skill.py — тексты и чипы      первый экран клиента
```

По `welcome/skill.py` пересечение реально: они правят тексты и чипы, ты — построение ссылок. **Скоординируйся через главное окно, а не молча.**

## Известное состояние

`MAX_BOT_<SLUG>_WEB_APP` задаётся **на каждого бота отдельно** (`apps/channels/bot_registry.py:258-259`) — поэтому салонный бот Mini App открывает. Пустой только глобальный `settings.MAX_MINIAPP_URL`, который читает клиентское приветствие (`apps/skills/welcome/skill.py:655,822`).

Токены дизайна расходятся: `apps/miniapp/src/styles/tokens.css:31` даёт `#c47b6c` с пометкой PLACEHOLDER, `djangoproject/DESIGN.md:33` объявляет `#7B6CF6`. **Решение владельца не принято — не выбирай сам**, это открытый пункт реестра.

## Правила

Своё дерево от свежего `origin/dev`, в чужие не входить (`git worktree list`). PR против `dev`, не против `main`. Мержит владелец.

Секреты не печатать. Не прогонять проверки в откатываемой транзакции на пилотной базе (`docs/HANDOFF_MAIN_WINDOW.md` §0-ter). `cancelled` в `gh pr checks` — отменённый дубликат, не падение.

Опровержение постановки ценнее согласия — с `файл:строка`.
